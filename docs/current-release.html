v1.3.14 — November 3, 2026 (prepared)

Sequential preview downloads, overall progress and completion tone

  • FIFO download queue: Download on another photo/video no longer cancels a running transfer; files download in selection order.
  • Swiping photos or leaving the viewer keeps queued transfers running while the app remains open; repeated taps do not duplicate active entries.
  • Overall queue progress in the viewer and gallery shows finished/total, remaining files, current filename, failures and a file-count progress bar (not byte progress).
  • Android plays one system notification tone when the full preview queue ends, following the phone's sound settings.
  • Failed files can be retried without stopping other queued transfers; downloaded markers update in the gallery.
  • The viewer queue is not persistent after force-closing the application; background batch downloads use a separate Android service.
  • Version: 1.3.14+23. Publication follows the signed GitHub release workflow.

v1.3.14 — 3 ноября 2026 (подготовлена)

Очередь загрузок из просмотра, общий прогресс и звуковой сигнал

  • Очередь FIFO: Download для следующего фото или видео не отменяет текущую загрузку; файлы скачиваются в порядке добавления.
  • Перелистывание и выход из просмотра не прерывают очередь, пока приложение работает; повторные нажатия не добавляют дубликаты.
  • Общий прогресс в просмотре и галерее: скачано/всего, осталось, текущий файл, ошибки и полоса прогресса (по файлам, не по байтам).
  • Один системный звук Android после завершения всей очереди, с учётом настроек телефона.
  • Ошибочные файлы можно повторить, не останавливая остальные загрузки; зелёные отметки обновляются в галерее.
  • Очередь просмотра не переживает принудительное закрытие приложения; пакетная фоновая загрузка Android работает отдельно.
  • Версия: 1.3.14+23. Публикация через существующий подписанный GitHub Release.

v1.3.14 — 3 листопада 2026 (підготовлена)

Черга завантажень із перегляду, загальний прогрес і звуковий сигнал

  • Черга FIFO: Download для наступного фото чи відео не скасовує поточне завантаження; файли завантажуються в порядку додавання.
  • Гортання та вихід із перегляду не переривають чергу, доки застосунок працює; повторні натискання не додають дублікатів.
  • Загальний прогрес у перегляді та галереї: завершено/всього, залишилось, поточний файл, помилки та смуга прогресу (за файлами, не за байтами).
  • Один системний звук Android після завершення всієї черги, з урахуванням налаштувань телефону.
  • Невдалі файли можна повторити без зупинки інших завантажень; зелені позначки оновлюються в галереї.
  • Черга перегляду не переживає примусового закриття застосунку; фонове пакетне завантаження Android працює окремо.
  • Версія: 1.3.14+23. Публікація через наявний підписаний GitHub Release.
